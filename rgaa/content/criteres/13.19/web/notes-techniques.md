La personne utilisatrice peut définir des paramétrages spécifiques dans l’agent utilisateur ou dans le système d’exploitation. Dans la mesure du possible ces réglages doivent être respectés dans l’interface utilisateur sauf si leur surcharge est essentielle ou si cela est techniquement impossible (p. ex. indisponibiité de la valeur du réglage).

Les paramètres incluent notamment le contraste (modes Clair, Sombre ou Fort contraste p. ex.), la taille de police, les tailles du pointeur et du curseur.

P. ex. la propriété CSS force-color-adjust ou l’attribut booléen userscalable=0 de l’élément HTML `<meta>` d’attribut name valant viewport sont à utiliser avec précaution, uniquement dans le cas où cela est essentiel.
