title: "Les champs en erreur et dont la saisie requiert un type de données et/ou de format obligatoires vérifient-ils une de ces conditions ?"
conditions:
  - "* Une instruction ou une indication du type de données et/ou de format obligatoire est visible et accessible aux technologies d’assistance et est située dans le libellé associé au champ."
  - "* Une instruction ou une indication du type de données et/ou de format obligatoire est visible et accessible aux technologies d’assistance et est située dans le passage de texte associé au champ."
  - "* Le message d’erreur indiquant le caractère invalide de la saisie est situé dans le groupe de champs."
