---
title: 'Chaque balise possédant un attribut WAI-ARIA role="img" informative, qui nécessite une description détaillée, vérifie-t-elle une de ces conditions ?'
conditions:
  - "Il existe un attribut WAI-ARIA aria-label contenant le nom accessible et une référence à une description détaillée adjacente ;"
  - "Il existe un attribut WAI-ARIA aria-labelledby associant le nom accessible et un passage de texte faisant office de description détaillée ;"
  - "Il existe un attribut WAI-ARIA aria-describedby associant un passage de texte faisant office de description détaillée ;"
  - "Il existe un lien ou un bouton adjacent permettant d’accéder à la description détaillée."
